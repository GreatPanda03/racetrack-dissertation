# The Racetrack Game

## About the Repository

### Introduction
This repository tracks all development progress and documentation for the project, "[The Racetrack Game](https://campus.cs.le.ac.uk/teaching/proposals/v24167.the_racetrack_game)". The project is a game enabling players to race around tracks with vectors affected by their current speed and acceleration. 

### Commits
The GitLab repository contains the source code for the project. Occassional commits with source code have been provided. Each commit details new application functionality, changes, and removals. It also contains documentation for the application, such as its features and how to use it, provided in the Wiki section.

There are many commits from an account called GreatPanda3: this is myself.
